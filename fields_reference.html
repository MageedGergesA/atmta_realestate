Overview · مقدمة

EN: A field-by-field reference for every Odoo model in the Atmta Real Estate suite. Each table shows the technical field name, type, an English explanation, and the Egyptian-Arabic explanation in plain colloquial language.

عربي: مرجع لكل فيلد (Field) في كل موديل في نظام عتمتا للعقارات. كل جدول فيه اسم الفيلد التقني، نوعه، وشرح بالإنجليزي وبعده شرح بالمصري بكلام بسيط.

Legend / دليل: field_name = technical name (اسم تقني) · M2o = Many2one · O2m = One2many · M2m = Many2many · stored compute · required

realestate.property — Property / العقار

EN: The core record for any piece of real estate — could be a whole compound, a building, a floor, or one unit. Hierarchical: a building's child records can be floors, a floor's children are units.

عربي: ده الموديل الأساسي بتاع أي عقار سواء كومباوند، عمارة، دور، أو شقة. وممكن العقار يبقى تابع لعقار أكبر منه (مثلاً شقة تابعة لعمارة).
